# 数独 Sudoku

一个功能完整的数独游戏网页应用，支持三种难度、笔记模式、自动检查、提示系统、存档续玩、记录统计和打印练习。

## 功能特性

### 🎮 游戏功能
- **三种难度**：简单（36 空）、中级（46 空）、高级（54 空）
- **数字选择 + 擦除模式**：点击数字键盘选择要填入的数字，或切换到擦除模式
- **笔记模式**（铅笔 ✏️）：在格子中记录多个候选数字，辅助推理
- **撤销**：支持最多 30 步撤销操作（Ctrl+Z）
- **提示**：自动找到最佳空位填入正确数字
- **自动检查**：开关开启后实时高亮错误填入的数字
- **键盘全支持**：
  - `1-9` 选择数字
  - `Enter/Space` 填入选中数字
  - `Backspace/Delete/0` 擦除
  - `↑↓←→` 方向键导航
  - `P` 切换笔记模式
  - `H` 使用提示
  - `Ctrl+Z` 撤销

### 💾 存档与记录
- **自动存档**：游戏过程中自动保存进度，离开页面时自动保存
- **继续游戏**：首页显示存档进度，可一键续玩
- **最佳记录**：按难度记录最快完成时间、胜场、连胜等统计
- **新纪录标识**：刷新个人最佳时间时会有特殊标记

### 🖨️ 打印练习
- 生成含答案的打印版数独，适合线下练习

### 🧩 解题器（`solve.html`）
- 独立页面，可输入任意数独题目并自动求解
- 带渐进填充动画，支持冲突检测

## 快速开始

直接打开 `index.html` 即可使用，无需构建工具或服务器。

```bash
# 克隆或下载项目后，在浏览器中打开
open index.html
# 解题器
open solve.html
```

## 技术实现

纯前端单页应用，无外部依赖。

### 模块架构（`script.js`）

| 模块 | 职责 |
|------|------|
| **Generator** | 随机生成有效数独谜题，确保唯一解。对角线预填 → 回溯填充 → 剪枝挖空 |
| **Validator** | 冲突检测（行列宫）、终局判定、单格合法性判定。预计算 peer 关系加速 |
| **Storage** | 基于 `localStorage` 的存档/设置/记录持久化，含跨标签页同步 |
| **Timer** | 计时器，支持暂停/恢复/累积计时 |
| **UI** | DOM 渲染、事件绑定、棋盘/键盘/状态更新、动画效果 |
| **Game** | 游戏状态机（空闲 → 生成中 → 进行中 → 暂停 → 获胜），协调各模块 |
| **Solver** | 独立回溯求解器，用于 `solve.html` 页面 |
| **PrintGenerator** | 生成打印版本 |

### 状态机

```
idle → generating → playing ⇄ paused
                        ↓
                      won → idle
```
